II. 5 CHƯƠNG "SỐNG CÒN" CẦN ĐỌC TRONG TÀI LIỆU ĐỂ ĐI LÀM NGAY
--------------------------------------------------
1. PL/SQL Program Units: Cách viết Procedures và Functions (truyền tham số IN, OUT, IN OUT).
2. Packages: Cách tách biệt Specification (Phần khai báo) và Body (Phần thực thi).
3. Exception Handling: Cách bẫy lỗi để hệ thống không bị "treo" khi có sự cố.
4. Collections (Bulk Collect & Forall): Kỹ thuật xử lý hàng loạt giúp code chạy nhanh gấp 10-20 lần.
5. Cursors: Cách điều khiển luồng dữ liệu khi truy vấn từ SQL.

III. TÀI LIỆU VÀ HƯỚNG DẪN NÂNG CAO SAU NÀY (BỔ SUNG CHO KỸ SƯ ERP)
--------------------------------------------------
Ngoài 2 file trên, để trở thành chuyên gia (Senior), bạn cần học thêm:

1. Tối ưu hóa hiệu năng (Performance Tuning):
   - Tài liệu: Oracle Database SQL Tuning Guide.
   - Mục tiêu: Học về Index, Execution Plan để xử lý hàng triệu dòng dữ liệu trong vài giây.

2. Kiến thức nghiệp vụ (Business Logic):
   - Nguồn: Youtube "Oracle Learning" hoặc "Apps2fusion".
   - Mục tiêu: Hiểu quy trình Mua hàng (P2P), Bán hàng (O2C). Bạn không thể code đúng nếu không hiểu tiền và hàng chạy đi đâu.

3. Tích hợp và API (Integration):
   - Tài liệu: Oracle XML Developer's Kit Guide.
   - Công cụ: Postman.
   - Mục tiêu: Dùng gói DBMS_XMLGEN để xuất dữ liệu XML cho báo cáo hoặc gọi Web Service.

4. Quản lý Server Linux:
   - Công cụ: Putty, WinSCP.
   - Mục tiêu: Biết các lệnh Linux cơ bản (cd, ls, tail -f) để kiểm tra Log file trên server khi code bị lỗi.
