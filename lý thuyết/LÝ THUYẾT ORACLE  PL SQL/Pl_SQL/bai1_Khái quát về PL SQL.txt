KHÁI QUÁT VỀ PL/SQL (ORACLE) VÀ SO SÁNH VỚI T-SQL (SQL SERVER / MYSQL)
================================================================================

I. KHÁI QUÁT VỀ PL/SQL (ORACLE)
--------------------------------------------------------------------------------
1. PL/SQL la gi?
   - Viet tat cua: Procedural Language/Structured Query Language.
   - La ngon ngu mo rong tinh thu tuc (Procedural) danh rieng cho Oracle Database.
   - Ket hop suc manh truy van cua SQL voi cac cau truc lap trinh nhu vong lap, 
     re nhanh va xu ly loi.

2. Dac diem noi bat cua PL/SQL:
   - Cau truc khoi (Block-structured): Code duoc to chuc thanh cac khoi logic 
     gong DECLARE ... BEGIN ... EXCEPTION ... END;.
   - Hieu nang cao: Nhieu cau lenh SQL duoc gom thanh mot khoi PL/SQL va gui 
     den Oracle Server trong mot lan giao tiep, giam tai cho mang (Network Traffic).
   - Tinh dong goi cao: Ho tro Package (gom Spec va Body) giup quan ly code, 
     bao mat va tai su dung chuc nang cap doanh nghiep.
   - Xu ly loi manh me: Co che Exception Handling giup bat va xu ly loi linh hoat.
   - Luat va cu phap chat che: Dua tren phong cach ngon ngu Ada/Pascal, dam bao 
     code it loi va de bao trì.


II. KHÁI QUÁT VỀ T-SQL VÀ KHÁI NIỆM TƯƠNG ĐƯƠNG TRÊN SQL SERVER / MYSQL
--------------------------------------------------------------------------------
1. T-SQL (Transact-SQL) tren MS SQL Server:
   - La ngon ngu mo rong thu tuc danh rieng cho Microsoft SQL Server.
   - Cu phap linh hoat, cu an, lai giua SQL chuan va phong cach C/Sybase.
   - Tap trung vao tinh nhanh gon va thao tac tap hop (Set-based processing).

2. Khai niem tuong duong tren MySQL:
   - MySQL khong goi la T-SQL hay PL/SQL, ma su dung "Stored Routines" 
     (Procedure, Function, Trigger) theo chuan SQL/PSM.
   - Tinh nang thu tuc cua MySQL don gian hon va it tinh nang nang cao hon Oracle.

IV. ĐIỂM GIỐNG NHAU GIỮA PL/SQL VÀ T-SQL / MYSQL
--------------------------------------------------------------------------------
1. Muc tieu chung:
   - Deu mo rong SQL chuan de thuc hien logic lap trinh phuc tap tren Server.
   - Deu ho tro tao Stored Procedure, Function, Trigger va DML (SELECT, INSERT...).

2. Khai niem can ban:
   - Deu co bien, kieu du lieu, cau truc rẽ nhanh (IF...ELSE), vòng lap (WHILE/LOOP).
   - Deu ho tro Con tro (Cursor) de duyet qua tung dong du lieu.
   - Deu dam bao tinh toan ven giao dich (Transaction Management: COMMIT, ROLLBACK).


V. TÓM TẮT DÀNH CHO NGUỜI HỌC ORACLE
--------------------------------------------------------------------------------
- PL/SQL cua Oracle la ngon ngu thu tuc chuan va toan dien nhat trong cac DBMS.
- Khi da nam vung PL/SQL, ban se thay T-SQL (SQL Server) va MySQL rat de dung 
  vi cu phap cua chung thong thoáng va it quy tac hon.
- T-SQL va MySQL tap trung vao su nhanh gon, trong khi PL/SQL huong den kien truc 
  he thong lon, tinh dong goi va do tin cay cao.
