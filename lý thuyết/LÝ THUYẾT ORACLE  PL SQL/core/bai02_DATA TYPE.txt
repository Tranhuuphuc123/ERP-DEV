================================================================================
HỆ THỐNG KIỂU DỮ LIỆU: SQL SERVER | MYSQL | ORACLE
================================================================================

1. NHÓM KIỂU CHUỖI (KÝ TỰ & VĂN BẢN)
--------------------------------------------------------------------------------
* SQL SERVER (MSSQL):
    - CHAR(n) / VARCHAR(n): Không hỗ trợ tiếng Việt (Non-Unicode).
    - NCHAR(n) / NVARCHAR(n): CÓ TIẾNG VIỆT (Unicode). Thường dùng NVARCHAR(50/255).
    - NVARCHAR(MAX): Lưu văn bản cực lớn (thay thế cho NTEXT cũ).

* MYSQL:
    - CHAR(n) / VARCHAR(n): Hỗ trợ tiếng Việt nếu cấu hình Charset là utf8mb4.
    - TEXT / LONGTEXT: Lưu văn bản dài và siêu dài.

* ORACLE:
    - VARCHAR2(n): Kiểu phổ biến nhất, lưu chuỗi động.
    - NVARCHAR2(n): Chuyên dùng lưu Unicode (Tiếng Việt).
    - CLOB / NCLOB: Lưu văn bản lớn (Character Large Object).

* MẸO NHỚ: MSSQL và Oracle cần có chữ "N" (National) để chắc chắn lưu được tiếng Việt có dấu.


2. NHÓM KIỂU SỐ (NUMBER)
--------------------------------------------------------------------------------
* SQL SERVER:
    - INT: Số nguyên tiêu chuẩn.
    - BIGINT: Số nguyên lớn.
    - DECIMAL(p,s): Số thập phân chính xác (Dùng cho tiền tệ).
    - BIT: Lưu 0 hoặc 1 (Dùng cho True/False).

* MYSQL:
    - INT: Số nguyên.
    - DECIMAL(p,s): Số thập phân chính xác.
    - BOOLEAN: Thực chất là TINYINT(1), lưu 0 và 1.

* ORACLE:
    - NUMBER(p,s): Kiểu số vạn năng (Dùng cho cả số nguyên và số thập phân).
    - BINARY_FLOAT / BINARY_DOUBLE: Số thực dấu phẩy động.


3. NHÓM NGÀY THÁNG (DATE & TIME)
--------------------------------------------------------------------------------
* SQL SERVER:
    - DATE: Chỉ ngày (YYYY-MM-DD).
    - DATETIME / DATETIME2: Ngày và giờ.

* MYSQL:
    - DATE: Chỉ ngày.
    - DATETIME: Ngày và giờ cố định.
    - TIMESTAMP: Ngày và giờ (Tự động chuyển đổi theo múi giờ).

* ORACLE:
    - DATE: Lưu cả ngày và giờ (Mặc định của Oracle).
    - TIMESTAMP: Lưu ngày giờ với độ chính xác đến mili giây.


4. CÁC RÀNG BUỘC PHỔ BIẾN (CONSTRAINTS) - DÙNG CHUNG CẢ 3 HỆ THỐNG
--------------------------------------------------------------------------------
1. NOT NULL: Không được để trống.
2. UNIQUE: Giá trị duy nhất, không trùng.
3. PRIMARY KEY: Khóa chính (Định danh hàng).
4. FOREIGN KEY: Khóa ngoại (Liên kết bảng).
5. DEFAULT: Giá trị mặc định. 
   - MSSQL ví dụ: [Ten] NVARCHAR(50) DEFAULT N'Vô danh'
6. CHECK: Điều kiện kiểm tra (Ví dụ: Age >= 18).


5. BẢNG SO SÁNH NHANH (QUY ĐỔI TƯƠNG ĐƯƠNG)
--------------------------------------------------------------------------------
| Đặc điểm        | SQL Server (MSSQL) | MySQL               | Oracle            |
|-----------------|--------------------|---------------------|-------------------|
| Tiếng Việt      | N'Nội dung'        | utf8mb4             | NVARCHAR2         |
| Tự động tăng    | IDENTITY(1,1)      | AUTO_INCREMENT      | GENERATED BY DEFAULT AS IDENTITY   
| Đúng/Sai        | BIT                | BOOLEAN (TINYINT)   | NUMBER(1)         |
| Văn bản lớn     | NVARCHAR(MAX)      | LONGTEXT            | CLOB / NCLOB      |
| Ngày tháng      | DATETIME           | DATETIME            | DATE              |

================================================================================
LƯU Ý KHI CODE:
- MSSQL: Khi nhập dữ liệu tiếng Việt phải có chữ N phía trước: N'Phúc Aptech'.
- MySQL: Phải đảm bảo DB tạo với COLLATION là utf8mb4_unicode_ci.
- Oracle: Độ dài VARCHAR2 tối đa thường là 4000 bytes (hoặc 32767 tùy cấu hình).
